## 总体结论

1. 48 组确认实验没有推翻前一轮方向，反而把主线收窄得更清楚：收益优先组合是 `quality_light_no_valuation + loose_no_prior + RPS 70 + 50/120/250 + RPS exit 80`。
2. `value_quality` 没有赢过收益基线，但它的验证收益接近、训练回撤显著更小，是更适合作为风控/实盘观察的候选。
3. `growth_ocf` 的收益弹性不足，训练期交易数太少；它适合作为低回撤参考，不适合作为当前默认。
4. `loose_no_prior` 在配对验证收益上明显胜出，确认 K线宽松杯柄形态值得保留。
5. RPS 70 仍优于 RPS 80；RPS 80 主要减少交易数，但没有带来足够收益或回撤改善。
6. `50+120+250` 窗口优于 `120+250`，但回撤略深；收益默认用三窗口，风控观察可保留 `120+250`。
7. RPS 退出 80 优于 75。75 对训练期更友好，但验证期收益和评分更弱。
8. 新评分和验证期最终资金相关性很强：Spearman 约 +0.887。交易数相关性很低，说明评分已经不再机械偏好高交易量。

## 评分系统复查

新评分在 48 组确认实验上的相关性：

| 指标 | Pearson | Spearman |
|---|---:|---:|
| 验证终值 | +0.6240 | +0.8868 |
| 验证年化 | +0.6225 | +0.8868 |
| 验证总收益 | +0.6240 | +0.8868 |
| 验证交易数 | -0.0228 | +0.1365 |

判断：

- 评分和验证收益排序高度一致，当前公式可以继续使用。
- 评分和交易数相关性很低，说明低频友好调整生效了：它没有机械奖励高交易量。
- 评分对验证回撤几乎无相关。这不是 bug，而是当前评分把收益放在主位、回撤作为约束。如果要挑实盘默认，仍应同时看收益/回撤 Pareto，而不是只看 score。

## 下一步建议

1. Dashboard 默认参数可以先更新为“收益探索默认”，但保留“均衡观察默认”作为第二个预设。
2. 下一轮不建议继续扩大同一训练/验证拆分下的网格。更有价值的是对这 2-3 个候选默认做滚动窗口复验：
   - 训练 2014-2018，验证 2019-2022
   - 训练 2016-2020，验证 2021-2023
   - 训练 2018-2022，验证 2023-2026
3. 暂时不恢复 RPS 90/95、固定持有 130、`min_rps_windows_passing=2` 或严格放量杯柄到主网格。
4. 市场过滤继续单独作为覆盖层实验，不和财务/RPS/K线主参数混跑。
