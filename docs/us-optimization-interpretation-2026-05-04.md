# 美股参数优化结果解读与归因实验建议

日期：2026-05-04  
对象：美股参数优化 run #18（600/600，启用 K 线形态）与 run #19（16/16，关闭 K 线形态、20 持仓）

## 当前结果快照

run #18 是最新一轮宽松杯柄参数优化，已经恢复到可分析样本量：

- 完成参数组：600
- 失败参数组：0
- 每组完成交易数：约 127 到 308 笔
- 前 10 名年化收益：约 18.45% 到 30.94%
- 最优结果：rank #1 / result #1077，178 笔交易，年化 27.79%，最大回撤 -13.85%
- 最高年化结果：rank #3 / result #1309，163 笔交易，年化 30.94%，最大回撤 -18.38%

这说明上一轮极窄杯柄曲线导致的“小样本排名失真”已经明显缓解；当前结果更适合做下一步归因分析。

run #19 是关闭 K 线形态后的第一轮对照，但要注意它不是“只财务”策略，而是：

```text
财务：启用
RPS：启用
K线形态：关闭
portfolio_cap：20
position_weight_pct：5%
```

也就是说，它和 run #18 的差异不只有 K 线开关，还包括持仓上限从 10 提高到 20、单票权重从 10% 降到 5%。两轮总仓位上限都接近 100%，但 #19 更分散、更少依赖少数个股。

run #19 的结果：

- 完成参数组：16
- 失败参数组：0
- 每组完成交易数：294 到 611 笔，中位数约 460 笔
- 年化收益范围：-2.06% 到 16.12%，中位数约 7.22%
- 最大回撤范围：-17.36% 到 -42.93%，中位数约 -31.27%
- 最优结果：rank #1 / result #1444，294 笔交易，年化 16.12%，最大回撤 -21.72%
- 次优结果：rank #2 / result #1443，296 笔交易，年化 13.73%，最大回撤 -17.36%

初步结论：关闭 K 线后，交易数和候选数明显上升，但收益和回撤没有同步改善。即使把持仓从 10 增加到 20，#19 的最好结果仍低于 #18 的前排结果。这更支持一个判断：当前宽松杯柄形态不是单纯减少交易次数，而是在一定程度上提升了候选池质量或规避了较差买点。

但这还不能证明“杯柄形态一定有效”。#18 是从 600 组形态参数里选最优，#19 只有 16 组财务/RPS 对照；#18 存在更强的参数搜索优势。另外 #18 与 #19 的持仓上限不同，所以严格归因还需要同一持仓设置下复跑。

## 1. 持仓股票太少是否会错过大涨股

会，这是当前策略评估里非常关键的风险来源。

当前参数优化默认 `portfolio_cap=10`、`position_weight_pct=0.10`，即最多 10 只、单票约 10%。当某一天候选池很大时，系统会按筛选后的排序规则选前 10 个。如果某个后续涨幅巨大的股票当日没有进入前 10，或者因为已有持仓占满槽位而不能买入，组合收益会明显受影响。

这不是单纯的实现问题，而是策略定义的一部分：同一套筛选条件在“候选很多、持仓上限很低”的情况下，会变成一个强烈依赖排序和容量的策略。尤其当 K 线形态关闭后，候选池可能显著扩大，`portfolio_cap` 和排序规则会变成更大的收益驱动因素。

run #19 对这个问题提供了第一条证据：把持仓上限提高到 20 后，关闭 K 线形态的策略确实完成了更多交易，但收益并没有比 #18 更好，回撤反而更深。这说明“错过少数大涨股”不是当前唯一瓶颈；如果候选质量下降，扩大持仓只会把更多一般或较差候选买进组合。

因此，持仓上限需要和候选质量一起看：

- 如果候选池质量高，`cap=20` 可能降低错过大涨股的概率，并减少单票偶然性；
- 如果候选池质量低，`cap=20` 可能只是更充分地暴露在噪声候选里；
- 如果总仓位保持 100%，`cap=10/weight=10%` 和 `cap=20/weight=5%` 的核心差异是集中度，而不是杠杆或总风险预算。

建议后续不要只看单一 `portfolio_cap=10` 的结果。做 K 线形态归因时，最好同时测试：

- `portfolio_cap=10`：接近当前实盘约束
- `portfolio_cap=20`：观察错过大涨股是否明显缓解
- `portfolio_cap=50` 或更高：观察筛选条件本身的平均质量，而不是前 10 名排序能力

如果 cap 放大后收益显著改善，说明当前策略主要瓶颈可能不是筛选条件，而是候选排序和容量约束。

## 2. 形态差异是否会造成年化收益大幅波动

会，但要分两层理解。

第一层是真实影响：杯柄形态参数会改变哪些股票在哪一天进入候选池。一旦候选池变化，买入时点、持仓重叠、前 10 名排序都会变化，所以年化收益可能被明显放大或压低。

第二层是抽样和组合容量影响：如果两个杯柄参数只差一点，但刚好把某只大涨股纳入或排除，结果就会出现跳变。这种跳变不一定说明某个微小形态参数具有稳定预测力，也可能只是组合容量、排序和单个大样本共同造成的。

当前 #18 的前排结果已经不是 1 到 3 笔交易的小样本，但仍然需要做归因验证。判断 K 线形态是否真的有效，不能只比较 600 个带形态参数的排名，还要比较：

- 财务 + RPS + K 线形态
- 财务 + RPS，不启用 K 线形态
- 财务 + K 线形态，不启用 RPS
- RPS + K 线形态，不启用财务

只有这些对照组都跑过，才能把“形态本身的贡献”和“候选池/排序/容量效应”分开。

run #19 关闭 K 线后的表现说明，至少在当前 5 年区间里，K 线形态的影响很大。带形态的 #18 最优年化约 27.79%、最高年化约 30.94%；关闭形态的 #19 最高年化约 16.12%。更重要的是，#19 的交易数更多，却没有换来更高收益，这说明形态过滤可能在“少交易但提高平均买点质量”上有贡献。

不过，这个结论仍然需要防止两个误判：

- #18 是 600 组里挑出来的最优形态组合，存在参数优化过拟合风险；
- #19 的持仓和财务网格不同，不能作为完全干净的单变量实验。

所以当前更准确的说法是：K 线形态值得继续优化，但下一步必须用同一持仓、同一财务/RPS 设置做开关对照，而不是直接用 #18 和 #19 的绝对收益下最终结论。

## 3. 重跑 600 个但不考虑欧奈尔形态是否合适

合适，而且是下一步必须做的归因实验。

推荐第一轮对照不是完全关闭所有限制，而是只关闭 K 线形态，保留财务和 RPS：

```text
财务：启用
RPS：启用
K线形态：关闭
```

这样可以回答一个核心问题：当前 K 线形态到底是在提升收益，还是只是减少候选池、改变持仓分配。

但候选池变大后确实会引入第 1 点的问题：如果每天候选很多，`portfolio_cap=10` 会让策略更像“RPS 排序前 10 组合”，大涨股是否被选中会影响很大。因此建议这轮对照至少加一个容量轴：

```json
"portfolio_cap": [10, 20, 50]
```

如果关闭 K 线形态后：

- `cap=10` 表现差，但 `cap=50` 明显变好，说明问题主要是容量和排序；
- 所有 cap 都差，说明 K 线形态可能确实提高了候选质量；
- 所有 cap 都好于带形态，说明当前 K 线形态可能在过度排除有效股票。

run #19 已经覆盖了一个“关闭 K 线、cap=20、总仓位约 100%”的对照，结果更接近第二种情况：关闭形态后候选更多，但收益和回撤变差。因此短期内不建议完全放弃 K 线形态；更合理的方向是继续调整杯柄曲线，让它保留质量过滤能力，同时避免过度排除。

run #19 内部也给出了一些财务/RPS 方向：

- `selected_rps_windows=[50,120,250]` 明显优于只用 `[50,120]`。关闭 K 线后，长期 RPS 窗口能帮助减少噪声。
- 财务增长次数为 2 且同比门槛为 10% 或 20% 的结果靠前。最优 #1444 使用 3 年内 2 次增长、同比 20%，年化 16.12%；#1443 使用 2 次增长、同比 10%，年化 13.73% 且最大回撤较低。
- 财务门槛过宽时交易数会显著增加，但回撤也明显扩大。例如 1 次增长、宽松同比门槛的组合交易数接近 476 到 611 笔，最大回撤可到 -30% 到 -43%。

这说明当 K 线关闭后，财务过滤需要更严格，尤其需要强调“持续增长”而不是只满足一次增长。

## 4. 止损后本金减少是否已经考虑

部分考虑了，但不是完整逐日资金账户模拟。

当前实现里，单笔交易会严格计算止损：

- 如果当日开盘价低于止损价，用开盘价退出；
- 如果盘中最低价触及止损价，用止损价退出；
- 交易收益会进入结果的 `realized_return`；
- 优化指标里的组合曲线会把每个信号日的平均收益乘以仓位暴露后复利累乘。

因此，止损造成的亏损会降低后续组合权益，年化收益和最大回撤里已经反映了“亏损后本金变少”的效果。

但它目前不是完整的逐日资金账户模型。主要简化包括：

- 收益按信号日批次计入，而不是严格按实际退出日计入；
- 没有逐日 mark-to-market；
- 没有现金余额、滑点、手续费、股数取整；
- 持仓占用通过 `open_positions` 控制槽位，但组合权益曲线不是逐日按每只持仓市值更新。

所以当前曲线适合用于参数相对比较，但如果要做更接近实盘的收益曲线，后续需要增加逐日资金账户模拟。

## 下一步建议

本次已追加参数优化归因开关：财务、RPS、K 线形态可以分别启用或关闭。建议下一轮优先跑：

1. 财务 + RPS，关闭 K 线形态，`portfolio_cap=[10,20,50]`，并保持总仓位一致，例如 `10*10%`、`20*5%`、`50*2%`。
2. 财务 + RPS + K 线形态，用与 #19 相同的 `portfolio_cap=20`、`position_weight_pct=5%` 复跑，做干净的 K 线开关对照。
3. 优先固定 `selected_rps_windows=[50,120,250]`，财务网格重点围绕 `min_growth_count=2`、`min_yoy_growth_pct=[10,20]` 展开。
4. 在第 3 步基础上继续优化杯柄参数，而不是继续扩大无形态候选池。
5. 增加验证区间。#18 的 600 组存在 best-of-600 的过拟合风险，后续应至少拆出训练/验证区间，避免只优化 2025 年强行情下的偶然收益。

对比时不要只看最高年化，还要同时看完成交易数、最大回撤、收益回撤比、年度收益分布和不同 `portfolio_cap` 下的稳定性。

## 2026-05-04 追加实验：稳健目标与局部收敛方向

后续已经追加 `robust_annualized_return` 目标函数，并跑了两轮更适合防过拟合的样本：

- run #24：120/120 完成，目标为稳健年化收益，耗时约 33.7 分钟，最佳结果 #1665。
- run #26：114/150 完成后取消慢尾，已完成结果保留，最佳结果 #1828。

这两轮的意义不是寻找“历史最高年化”，而是观察哪些参数在训练期和验证期都不太差。结论比 #18 的 600 组更保守：

- 顶部稳健结果的训练期年化大多在 8% 到 10% 左右，验证期约 13% 到 20%，不像 #18 那样出现 25% 以上的高年化。
- 最大回撤明显更可控，run #26 最优结果的训练/验证回撤约 -5.17% / -7.99%。
- RPS 阈值从 85 向 90 收敛。run #26 前 30 名中 RPS 90 占 21 组，说明在稳健目标下，更强相对强度更重要。
- 财务条件不宜过严。前排多数仍是 3 年内 1 次净利润增长或 2 次增长，YoY 门槛以 0% 为主；过度提高财务增长门槛会减少候选，未必提升稳健收益。
- 杯深最大 45 是当前最稳定上界。杯深最小 10/12 更常见；传统 33 上界偏窄，55 又可能过宽。
- 前置上涨 true、把手高出右唇 2/5、把手最低位置 55 比较常见，说明形态不是完全无效，但应保持“宽松质量过滤”，不能回到极窄欧奈尔曲线。

策略层面的判断也随之调整：

1. #18 的高收益更像“宽松形态 + 随机搜索 + 单段行情”的上界提示，不能作为实盘预期。

## 2026-05-04 追加：PE/PB 替代方案与当前选择

PE/PB 有三类可选来源：

- 数据商直接给出的当前 PE/PB：获取简单，但历史回测容易把“今天知道的估值”带回过去。
- IBKR 或其他券商 fundamentals：适合实盘当日辅助筛选，但历史可得性、权限和字段稳定性仍需要单独验证。
- SEC companyfacts 自己计算：用已披露财报里的 EPS、股东权益、稀释股数，叠加信号日价格动态计算。

当前实现选择第三类作为正式回测口径。PE 优先用 `信号日收盘价 / diluted_eps`；没有 EPS 时用 `信号日收盘价 * 稀释股数 / 净利润`。PB 用 `信号日收盘价 * 稀释股数 / 股东权益`。只有 USD 财报才动态计算，非 USD 财报暂时不做 FX 换算。

这个选择的策略含义是：PE/PB 不再是“外部估值字段是否能抓到”的问题，而是“这家公司在当时披露的盈利、权益和股数，配合当时股价是否过贵”的问题。它更适合低频策略，也能把候选池压缩到财务质量更清楚、估值没有明显失控的股票。
