# 美股低频策略参数优化复盘与下一步策略

日期：2026-05-06

后续归因报告：

- [美股低频策略因子归因报告（2026-05-08）](./us-factor-attribution-report-2026-05-08.md)

## 样本范围

本次复盘使用数据库中已经完成或保留完整结果的优化 run。早期很短区间、启动失败或纯调试 run 不作为策略结论依据。

主要样本：

- run #18：600 组，2021-04-29 到 2026-04-29，启用财务 + RPS + K线形态，无验证区间。
- run #19：16 组，同区间，关闭 K线形态，持仓上限 20，用于粗略对照。
- run #23/#24/#26：训练 2021-04-29 到 2024-12-31，验证 2025-01-01 到 2026-04-29，主要用于观察训练/验证拆分后的参数稳定性。
- run #29 + #30：逻辑上是一组完整 124 组长期参考实验，训练 2018-01-01 到 2022-12-31，验证 2023-01-01 到 2026-04-30，资金账户口径为初始 100000、每笔 5000、最多 20 只持仓。

核心口径：有验证区间时优先看验证指标，同时看训练期是否也能活下来。只看验证期高收益会把 2023-2026 的强势行情误当成参数能力。

## 总体结论

1. 旧的高收益结果不可直接当作实盘预期。run #18 的最佳年化 27.8%，中位年化 10.5%，但它没有验证区间，且集中在 2021-2026 这一段。拆成训练/验证后，最稳健结果的训练期年化通常只有 8% 左右。
2. 长期参考样本 #29 + #30 显示当前策略在 2018-2022 训练段偏弱。前排结果经常是训练期接近 0 或略负、验证期转正。这说明策略更像“风险偏好回升后的成长股策略”，需要市场环境过滤，而不是继续单纯扩大杯柄形态参数。
3. 评分系统已经在 2026-05-06 做过复审和修正。旧 `robust_annualized_return` 在 #29+#30 里与验证期最终资金呈负相关，修正后与验证期最终资金的 Spearman 相关约 +0.62。后续判断以新评分的离线重算为准，数据库旧 run 的 `score/rank` 只保留为当时实验记录。
4. K线形态暂不能证明是稳定 alpha。新评分下 #29+#30 的无形态组收益最好，但回撤更深；strict 形态组收益低、交易少、回撤低。更准确的定位是：K线形态是风险/买点过滤器，不应默认假设它一定提高收益。
5. 财务数据仍是核心，但“越严格越好”不成立。轻财务条件收益弹性最高；经营现金流、PE/PB 会压缩候选池并降低回撤，但过严会导致交易数不足。下一轮应把收益基线和风控基线分开，而不是把 OCF/估值直接设成唯一默认。
6. RPS 仍应保留在主实验里，但不能再断言“不考虑 RPS 一定差”。RPS=0 只有 4 个负控样本，样本太少；新评分下它们收益并不差。下一轮需要少量但更平衡的 RPS-off 对照。

## 2026-05-06 评分复审更新

旧 `robust_annualized_return` 的问题是过度惩罚训练/验证差距：在 #29+#30 中，旧评分与验证期最终资金的 Spearman 相关约 -0.34，top 25% 的验证最终资金中位数反而低于 bottom 25%。这会把“验证收益高、训练期接近 0”的组合系统性压到后面。

新评分改为：

- 验证期年化收益为主权重。
- 训练/验证较低年化收益作为稳定性约束。
- 训练/验证差距、最大回撤、负训练收益作为软惩罚。
- 训练或验证交易数不足时加重惩罚。
- 缺失训练/验证年化收益时额外扣分，避免极小样本排到前列。

离线重算后：

- #29+#30：新评分与验证期最终资金 Spearman 约 +0.62，与验证年化约 +0.62。
- #24-#26：新评分与验证年化 Spearman 约 +0.98。
- #29+#30 新评分前排：#1903、#1951、#1982、#1879、#1945、#1939、#1950。

新评分改变了策略判断：收益靠前更多来自轻财务条件、无形态或宽松形态、不限持有、止损 -8%、RPS 70-85。严格财务和 strict 形态更像风险控制组，而不是收益最大化组。

## RPS 影响

短期稳健样本 #23-#26：

- RPS 85 的平均得分优于 RPS 90。
- `50+120+250` 窗口优于 `50+120`。
- RPS 退出 80 优于 75/85。

长期参考样本 #29+#30：

- 旧评分下 RPS 95 靠前，主要来自交易数少和回撤低；新评分下 95 排名下降，说明它更像防守过滤，不是收益主轴。
- 新评分下 RPS 70/80/85 的收益弹性更好，70 交易数最多但训练期更弱。
- RPS=0 只有 4 个样本，不能证明可行，但不应完全删除；需要更平衡的负控样本。
- `50+120`、`120+250`、`50+120+250` 差距不大，三者都可以在下一轮小样本里保留一次。

当前建议：

- 默认主测：`rps_threshold = [80, 85, 90]`。
- 保留低阈值容量测试：`70`，并补少量 RPS-off 负控。
- `95` 只作为防守组，并要求训练/验证交易数达到下限后才允许进入前排。
- 默认窗口：`50+120+250`；`50+120` 和 `120+250` 作为配对对照。
- `min_rps_windows_passing` 默认 2，但下一轮要保留 1 做容量对照。

## 财务影响

长期参考样本里，财务组的作用更像候选质量和风险控制。新评分复审后，这一点需要拆成两层：

- `quality_light_no_valuation` 新评分平均最高，验证收益也最高，但回撤中位约 -20.1%，训练期中位偏弱。它适合作为收益基线。
- 启用经营现金流、PE/PB 后，交易数和回撤明显下降。估值/现金流不是提高收益的万能药，更适合作为风控基线。
- 4 年严格增长、现金流严格组更稳，但交易数过少。交易数太少会让排名被少数股票支配。
- `value_quality`（PE≤30、PB≤5）目前表现偏弱，可能过度偏价值，和成长/RPS 策略方向冲突。

当前建议不再只有一个财务默认，而是两套配对：

收益基线：

```json
{
  "enabled": true,
  "min_years": 3,
  "min_growth_count": 1,
  "min_yoy_growth_pct": "0",
  "require_positive_net_income": true,
  "reporting_lag_days": 120,
  "max_pe": null,
  "max_pb": null,
  "require_positive_operating_cash_flow": false,
  "require_positive_free_cash_flow": false,
  "min_operating_cash_flow_growth_count": null
}
```

风控基线：

```json
{
  "enabled": true,
  "min_years": 3,
  "min_growth_count": 2,
  "min_yoy_growth_pct": "0",
  "require_positive_net_income": true,
  "reporting_lag_days": 120,
  "max_pe": "60",
  "max_pb": "15",
  "require_positive_operating_cash_flow": true,
  "require_positive_free_cash_flow": false,
  "min_operating_cash_flow_growth_count": null
}
```

保留两个对照：

- 估值收紧：`max_pe=40, max_pb=8`。
- 增长加强：`min_growth_count=2, min_yoy_growth_pct=5 或 10, min_operating_cash_flow_growth_count=1`。

暂时减少：

- `PE≤30/PB≤5` 不放入默认搜索，只保留少量价值对照。
- 自由现金流为正不作为默认要求，只作为严格风控对照。它会天然惩罚重资本开支公司，可能把部分优质成长股排除。

## K线形态影响

K线形态的结论比之前更清楚：

- run #18 带形态的最好结果明显优于 #19 关闭形态的最好结果，但两者持仓设置不同，所以只能算强提示。
- 旧评分下 strict 形态组更靠前；新评分下无形态组平均新分最高，验证收益更高，但回撤更深。
- strict 形态组的真实价值是降低交易数和回撤，而不是提高收益上限。
- 因此 K线形态不是可以直接删除的参数，但也不能作为默认必选结论。

当前 K线形态应保留为配对实验轴，不再继续扩大成大网格。建议用少量形态族：

主形态族：

- `base_prior_20`
- `base_volume_confirm`
- `strict_relaxed_lip`

机会形态族：

- `broad_mid`
- `loose_prior_10`

负控：

- `none`，用于衡量 K线形态是否真的增益。

暂时删除或降权：

- `loose_no_prior`：不直接删除；它在新评分前排出现过，但只作为宽松收益对照。
- `shallow_broad`：样本少且没有明显优势。
- 传统极窄 `oneil_strict` 不能直接删除，但只作为小样本严格对照；它得分靠前可能来自交易数少。

参数范围建议：

```json
{
  "min_cup_depth_pct": ["8", "10", "12"],
  "max_cup_depth_pct": ["45", "55"],
  "min_handle_pullback_pct": ["1", "2"],
  "max_handle_pullback_pct": ["12", "20"],
  "max_right_lip_delta_pct": ["5", "10"],
  "min_handle_low_position_pct": ["55", "66"],
  "max_handle_depth_to_cup_depth_pct": ["35", "60"],
  "max_handle_high_above_lip_pct": ["2", "5"],
  "require_prior_uptrend": [true],
  "min_prior_uptrend_pct": ["20"],
  "require_breakout_volume": [false, true]
}
```

固定不再作为默认优化轴：

- 杯底区域、杯底停留天数、杯底跨度、杯底两侧比例。
- 杯身/把手/整体周期。
- 形态回看窗口。
- 突破量均线天数。

这些参数先固定在宽松候选池默认值，等主策略稳定后再单独做小实验。

## 交易参数

止损：

- 短期稳健样本和长期现金账户样本都偏向 -8%。
- -10% 和 -12% 没有稳定优势；-6% 有时回撤低，但容易过早出局。
- 默认使用 -8%。下一轮主实验只固定 -8%，另开小样本测试 `[-0.06, -0.10, -0.12]`，不要让止损轴继续放大主网格。

RPS 退出：

- 短期稳健样本偏向 80。
- 长期样本 75/80/85 差距不大，前排同时出现 75 和 80。
- 默认使用 80；下一轮保留 `[75, 80, 85]` 做配对，但优先观察它和持有期、RPS 阈值的交互，不单独扩大解释。

持有交易日：

- 新评分下长期现金账户样本明显偏向不限持有，验证收益更高。
- 130 日仍有风控意义，适合作为趋势过长时的退出对照。
- 260 日暂时没有优势。
- 收益探索默认 `holding_days=null`；风控基线保留 130；删除或极少量保留 260。

进场延迟：

- 0/1/2 差异不稳定。
- 新评分前排同时出现 0/1/2，说明它可能和形态宽松度有关。
- 下一轮不把它作为主轴；收益探索默认 0，配对实验里少量保留 1 和 2。

持仓：

- 当前低频实盘口径建议 `portfolio_cap=20`、每笔 5000、初始 100000。
- 后续容量实验可以比较 `cap=10/20/50`，但不要和主参数网格混在一起，否则组合数会膨胀且归因变乱。

## 建议引入的新参数

最需要新增的不是更多杯柄曲线，而是市场环境和执行约束。

1. 市场环境过滤

当前长期训练段弱，优先考虑加入：

- SPY 或 Nasdaq 指数收盘价高于 200 日均线。
- 指数 50 日均线高于 200 日均线。
- 指数自身 20/60 日收益为正。

这是为了避免成长/RPS 策略在系统性熊市里持续开仓。该参数应先作为开关做配对实验，不要一上来做复杂多值网格。

2. 流动性和价格过滤

低频实盘需要避免不可交易的小票：

- 最低股价，例如 `close >= 10`。
- 20 日平均成交额，例如 `avg_dollar_volume_20 >= 20,000,000`。
- 可选：排除 ETF/基金/特殊证券，保留普通股。

3. 候选排序参数

当候选池大于持仓上限时，排序本身会决定买入对象。现在不能只看筛选条件，还要把排序作为策略的一部分：

- RPS 分数权重。
- 财务质量分权重。
- 估值惩罚权重。
- K线突破/形态质量分权重。

第一版可以先不做复杂优化，只实现一个固定综合排序，并和当前排序做 A/B。

4. 最小样本数约束

长期样本里部分高排名来自很少交易或训练期偏弱。评分已经增加样本不足和训练失败惩罚；后续页面展示也应该显式标记：

- 训练期完成交易数低于 30 的结果，不进入默认排名前列。
- 验证期完成交易数低于 50 的结果，排名降权或标记为“小样本参考”。
- 训练期年化低于 -3% 时，评分惩罚明显变陡；低于 -5% 的结果应标记为“训练期失败，需市场过滤解释”。

## 建议删除或减少的参数

可以从默认优化空间里减少：

- RPS=0：不进入主搜索，但要保留少量、平衡的负控样本。
- RPS 95：只作为防守组，不作为收益主轴。
- 止损 -10% 和 -12%：不放入主实验，只做小样本风险对照。
- 持有 260 日。
- 进场延迟 2 日：不做主轴，只保留少量配对。
- 过宽形态：`shallow_broad` 降权；`loose_no_prior` 不删除，只作为宽松收益对照。
- 杯柄底部结构参数、周期参数、形态回看窗口、突破量均线天数。
- `PE≤30/PB≤5` 价值强约束，除非单独研究价值风格。

不要删除：

- K线形态开关。它是必要负控。
- 宽松形态组。它是观察收益弹性的机会组。
- `120+250` RPS 窗口。新评分前排出现过，至少再保留一轮配对。
- 估值和现金流参数。它们对收益不一定最强，但对风险和候选池压缩有用。

## 下一轮实验计划

不建议马上继续跑几百上千组大随机。下一轮应做小规模配对实验，保证每个变量有干净对照。

### 实验 A：K线形态归因

目标：确认 K线形态在长期样本里到底是提高质量，还是只是降低交易数。

建议组合：

- 财务：`quality_light_no_valuation`、`quality_ocf`
- RPS：70、80、85
- 窗口：`50+120`、`120+250`、`50+120+250`
- K线：`none`、`loose_no_prior`、`base_volume_confirm`
- 止损：-8%
- RPS 退出：75、80
- 持有：不限

组合数约 `2 * 3 * 3 * 3 * 2 = 108`。如果要压缩到夜间 8 小时内，先固定 RPS 退出 80，组合数变成 54。

### 实验 B：RPS 阈值/窗口配对

目标：确认 70/80/85/90/95 的真实贡献，并避免 95 因交易数少虚高。

建议组合：

- 财务：`quality_light_no_valuation`、`valuation_tight`
- K线：`none`、`base_volume_confirm`
- RPS：70、80、85、90、95
- 窗口：`50+120`、`120+250`、`50+120+250`
- `min_rps_windows_passing`：1、2
- 止损：-8%
- RPS 退出：80
- 持有：不限

组合数约 `2 * 2 * 5 * 3 * 2 = 120`。如果先跑小样本，去掉 RPS 95 或固定 `min_rps_windows_passing=1`，压到 48-60 组。

### 实验 C：财务严格度与风险

目标：确认轻财务的收益弹性是否只是候选池更大导致，以及估值/现金流到底买来了多少风险下降。

建议组合：

- 财务：`quality_light_no_valuation`、`growth_ocf`、`valuation_growth_tight`、`quality_ocf`、`value_quality`
- RPS：80、85
- 窗口：`50+120+250`
- K线：`none`、`base_volume_confirm`
- 止损：-8%
- RPS 退出：80
- 持有：不限、130

组合数约 `5 * 2 * 2 * 2 = 40`。

### 实验 D：市场环境过滤

优先级上调。长期训练段弱的问题很可能来自系统性熊市里仍持续开仓，因此市场环境过滤应该先于继续扩大杯柄参数。

已实现的第一版参数：

- `market_filter=none`：不做市场过滤。
- `market_filter=spy_200ma`：只在 SPY 收盘价高于 200 日均线时允许新开仓。
- `market_filter=spy_50_200ma`：只在 SPY 收盘价高于 200 日均线，且 SPY 50 日均线高于 200 日均线时允许新开仓。

过滤只影响新开仓，不影响已有持仓按止损、RPS 退出或持有期结算。这样可以测试“是否应该停止新增风险暴露”，而不是粗暴改写已有交易的退出逻辑。

当前实验 D 使用 24 个核心组合：

- 财务：`quality_light_no_valuation`、`quality_ocf`
- RPS：80、85
- 窗口：`120+250`、`50+120+250`
- K线：`none`、`loose_no_prior`、`base_volume_confirm`
- 止损：-8%
- RPS 退出：80
- 持有：不限
- 持仓：20，每笔 5000，初始 100000

组合数约 `24 * 3 = 72`。

按当前 2 worker 的速度，72 组长期实验预计约 9-12 小时。不要用 6 worker；之前机器重启和虚拟内存压力说明当前机器更适合 2 worker 稳定跑。

run #31 已完成第一版 SPY 过滤配对。结果没有支持“直接启用 SPY 过滤作为默认”：24 个配对核心格子里，按验证期年化收益看，不过滤胜出 20 个，`spy_200ma` 胜出 4 个，`spy_50_200ma` 胜出 0 个。按新评分看，不过滤胜出 17 个，`spy_200ma` 胜出 4 个，`spy_50_200ma` 胜出 3 个。市场过滤确实降低了训练期交易数和部分回撤，但对验证期收益的拖累更明显。

因此下一组不继续扩大严格 SPY 过滤，而是改跑 `market_filter_experiment_d2`：

- 市场代理：`QQQ`，更贴近成长股/RPS 策略的风险偏好环境。
- 过滤组合：`none`、`qqq_100ma`、`qqq_150ma`、`qqq_200ma`。
- 不加入 `50/200MA` 强趋势确认；run #31 显示这个条件过严，容易牺牲收益。
- 仍使用同一批 24 个核心组合，组合数 `24 * 4 = 96`，方便和 run #31 做配对比较。

run #32 已完成 QQQ 过滤配对。结果比 SPY 温和，但仍不支持把市场过滤放进下一轮主实验默认：

- 按验证期年化收益看，不过滤胜出 13/24 个核心格子，`qqq_200ma` 胜出 7 个，`qqq_150ma` 胜出 4 个，`qqq_100ma` 胜出 0 个。
- 按新评分看，不过滤胜出 13 个，`qqq_150ma` 胜出 7 个，`qqq_100ma` 胜出 4 个，`qqq_200ma` 胜出 0 个。
- QQQ 过滤的主要价值是降低训练期回撤和交易数：训练期低回撤胜出里 `qqq_100ma/150ma/200ma` 合计 22/24，但验证收益中位数仍低于不过滤。
- 当前结论：市场过滤保留为风险控制候选，暂不混入实验 A/B/C。剩余归因实验需要保持 `market_filter=none`，先把 K线、RPS、财务严格度本身的贡献看清楚。
